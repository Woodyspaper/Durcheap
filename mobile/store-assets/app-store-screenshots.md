# App Store Screenshots Guide

## iOS Screenshots Requirements

### iPhone Screenshots (Required)
- **6.7" Display (iPhone 14 Pro Max, 15 Pro Max)**: 1290 x 2796 pixels
- **6.5" Display (iPhone 11 Pro Max, XS Max)**: 1242 x 2688 pixels  
- **5.5" Display (iPhone 8 Plus)**: 1242 x 2208 pixels

### iPad Screenshots (Optional but Recommended)
- **12.9" iPad Pro**: 2048 x 2732 pixels
- **11" iPad Pro**: 1668 x 2388 pixels

## Android Screenshots Requirements

### Google Play Store
- **Phone**: Minimum 320px, Maximum 3840px
- **7-inch Tablet**: Minimum 320px, Maximum 3840px  
- **10-inch Tablet**: Minimum 320px, Maximum 3840px

## Screenshot Content Strategy

### Screenshot 1: Home Screen & Product Browsing
- Show main marketplace with categories
- Featured products and search functionality
- Clean, professional interface

### Screenshot 2: Shop Local Feature
- Highlight location-based shopping
- Local delivery options
- Community marketplace benefits

### Screenshot 3: Seller Dashboard
- Professional seller tools
- Product management interface
- Analytics and insights

### Screenshot 4: Event Marketing
- Event advertising features
- Local event discovery
- Marketing campaign tools

### Screenshot 5: Secure Shopping
- Cart and checkout process
- Payment security features
- Order tracking capabilities

## App Preview Video (Optional)
- Duration: 15-30 seconds
- Show core app functionality
- Professional narration or text overlay
- Highlight unique selling points

## Asset Creation Tools
- Use Figma, Adobe XD, or Sketch for design
- Screenshot actual app interface on devices
- Ensure high-quality, non-pixelated images
- Include device frames for professional appearance
