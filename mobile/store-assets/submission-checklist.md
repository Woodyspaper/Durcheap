# App Store Submission Checklist

## Pre-Submission Requirements

### Development Accounts
- [ ] Apple Developer Program membership ($99/year)
- [ ] Google Play Console account ($25 one-time fee)
- [ ] Expo Application Services (EAS) account

### App Configuration
- [ ] Unique bundle identifier configured
- [ ] Version numbers set correctly
- [ ] Build numbers incremented for updates
- [ ] App permissions properly declared

## iOS App Store Submission

### App Store Connect Setup
- [ ] App created in App Store Connect
- [ ] Bundle ID matches development configuration
- [ ] App name available and reserved
- [ ] Primary language set to English (U.S.)
- [ ] Category selected: Shopping
- [ ] Age rating completed: 4+

### Required Assets
- [ ] App icon (1024x1024 PNG, no transparency)
- [ ] iPhone screenshots (1290x2796 for 6.7" display)
- [ ] iPad screenshots (2048x2732, if supporting tablets)
- [ ] App preview video (optional, 15-30 seconds)

### App Information
- [ ] App description (under 4000 characters)
- [ ] Keywords (under 100 characters)
- [ ] Support URL provided
- [ ] Marketing URL provided
- [ ] Privacy policy URL provided

### Build Upload
- [ ] Production build created via EAS Build
- [ ] Build uploaded to App Store Connect
- [ ] Build processed successfully
- [ ] TestFlight testing completed (optional)

### Review Information
- [ ] Contact information provided
- [ ] Demo account credentials (if required)
- [ ] Review notes for special features
- [ ] App content and functionality documented

## Google Play Store Submission

### Play Console Setup
- [ ] App created in Play Console
- [ ] Package name matches development configuration
- [ ] App signing key uploaded or managed by Google
- [ ] Store listing information completed

### Required Assets
- [ ] High-res icon (512x512 PNG)
- [ ] Feature graphic (1024x500 PNG)
- [ ] Phone screenshots (minimum 1080x1920)
- [ ] Tablet screenshots (if supporting tablets)

### Store Listing
- [ ] App title (under 50 characters)
- [ ] Short description (under 80 characters)
- [ ] Full description (under 4000 characters)
- [ ] Category selected: Shopping
- [ ] Content rating completed

### App Bundle Upload
- [ ] Production AAB created via EAS Build
- [ ] Bundle uploaded to Play Console
- [ ] Release notes provided
- [ ] Rollout percentage set (100% for initial release)

### Policy Compliance
- [ ] Privacy policy accessible and compliant
- [ ] Data safety form completed
- [ ] Target audience selected
- [ ] Permissions usage justified

## Testing and Quality Assurance

### Functional Testing
- [ ] App launches successfully
- [ ] All core features working
- [ ] Authentication flow tested
- [ ] Shopping cart and checkout functional
- [ ] Seller dashboard operational
- [ ] Event marketing features working

### Performance Testing
- [ ] App loads quickly on target devices
- [ ] No crashes during normal usage
- [ ] Memory usage within acceptable limits
- [ ] Network connectivity handled gracefully

### Device Testing
- [ ] iPhone (latest 2-3 models)
- [ ] iPad (if supporting tablets)
- [ ] Android phones (various screen sizes)
- [ ] Android tablets (if supporting tablets)

### Platform Guidelines Compliance
- [ ] iOS Human Interface Guidelines followed
- [ ] Material Design guidelines followed (Android)
- [ ] Accessibility features implemented
- [ ] Privacy and security best practices

## Legal and Compliance

### Privacy and Data Protection
- [ ] Privacy policy comprehensive and accessible
- [ ] GDPR compliance (if targeting EU users)
- [ ] CCPA compliance (if targeting California users)
- [ ] Data collection practices documented

### Terms of Service
- [ ] Terms of service available
- [ ] User agreements for marketplace transactions
- [ ] Seller terms and conditions
- [ ] Commission and fee structures documented

### Content Guidelines
- [ ] No prohibited content
- [ ] User-generated content moderation
- [ ] Reporting mechanisms for inappropriate content
- [ ] Age-appropriate content verification

## Post-Submission Monitoring

### App Review Process
- [ ] Monitor review status daily
- [ ] Respond to reviewer questions promptly
- [ ] Address any rejection reasons quickly
- [ ] Prepare for potential re-submission

### Launch Preparation
- [ ] Marketing materials ready
- [ ] Social media announcements prepared
- [ ] Press release drafted
- [ ] Customer support ready for user inquiries

### Performance Monitoring
- [ ] App analytics configured
- [ ] Crash reporting enabled
- [ ] User feedback monitoring setup
- [ ] Performance metrics tracking

## Estimated Timeline
- **iOS Review**: 1-7 days (typically 24-48 hours)
- **Google Play Review**: 3-7 days
- **Total Process**: 1-2 weeks including preparation

## Common Rejection Reasons
1. Missing or incomplete metadata
2. App crashes or doesn't work as described
3. Privacy policy issues
4. Inappropriate content
5. Guideline violations
6. Technical issues or bugs
