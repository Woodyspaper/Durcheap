## Data Sharing

### Data Shared with Third Parties
- **Payment Processors** (Stripe, PayPal): Payment information for transaction processing
- **Shipping Partners** (USPS, UPS, FedEx): Shipping addresses for order fulfillment
- **Analytics Services** (Firebase, Mixpanel): Usage data for app improvement
- **Customer Support** (Zendesk): Support tickets and user communications

### Data Not Shared
- Personal identification information
- Financial details beyond payment processing
- Private communications between users
- Sensitive business information

## Data Security

### Encryption
- [x] **Data in transit** - HTTPS/TLS encryption
- [x] **Data at rest** - Database encryption

### Security Measures
- Multi-factor authentication support
- Regular security audits
- Secure data storage practices
- Access controls and permissions

## User Controls

### Data Access
- Users can view their account data
- Download personal information
- Access transaction history

### Data Deletion
- Users can delete their accounts
- Request data removal
- Automatic data purging after account deletion

### Data Portability
- Export account data
- Download purchase history
- Transfer seller profile information

## Compliance

### Regulations
- GDPR compliance for EU users
- CCPA compliance for California users
- COPPA compliance (no data collection from children under 13)
- PCI DSS compliance for payment processing

### Age Restrictions
- App rated for ages 4+ (no children-specific features)
- No targeted data collection from minors
- Parental consent required for users under 13
