# Mobile App Assets

This directory contains the assets for the Durcheap mobile app.

## Required Assets

### App Icon
- **icon.png**: 1024x1024 PNG app icon
- **adaptive-icon.png**: 1024x1024 PNG adaptive icon for Android

### Splash Screen
- **splash.png**: 1242x2436 PNG splash screen image

### Favicon
- **favicon.png**: 48x48 PNG favicon for web version

## Asset Guidelines

- Use high-quality PNG images
- Follow platform guidelines for icon design
- Ensure icons work well on both light and dark backgrounds
- Test icons at various sizes to ensure clarity

## Creating Assets

You can create these assets using:
- Design tools like Figma, Sketch, or Canva
- Online icon generators
- Professional design services

For now, the app will use placeholder assets from Expo.
